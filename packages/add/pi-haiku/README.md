# @lukisxyz/pi-haiku

Structured header, footer, and live timer for [Pi](https://pi.dev) based on `pi-haiku` / `nocte`.

Preserves whatever theme is active in Pi (e.g. `omarchy-system`) without injecting or overriding color palettes.

## Features

- **Header**: shortcuts grouped by control, models, view, and input.
- **Footer**: directory path, Git branch, session name, provider, model, thinking effort, context usage bar, token metrics, cost, and live timer.
- **Theme neutral**: follows Pi's active theme.

## Usage

Type `/haiku` to toggle header and footer on or off.
